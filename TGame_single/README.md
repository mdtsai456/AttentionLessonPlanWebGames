# 勇闖迷宮・單人

第一人稱走在路中央，左右各出現一個物品。題目給一個類別，玩家選左邊或右邊。選單代號是 `TGame`，成績 `lessonId` 是 `1140908_TGame`。

## 一局怎麼進行

共 6 關，每關 60 秒。時間內可以連續作答。打完第 3 關會先存中場成績，並可以回大廳。六關結束再存一次。

預設題目寫在 `app.js` 的 `DEFAULT_STAGE_RULES`，例如「可以吃的食物」「可以坐的家具」。開局會先讀 `asset/主題資料.csv`。讀得到就從裡面抽 6 個主題；讀不到就用預設題，並在畫面上提示。

CSV 每一列是一個主題，分成正確項目與錯誤項目。畫面上的物品圖放在 `img/items/`。場景、走路與轉向的圖在 `img/`。

視窗太窄時，`shared/tgame-support.js` 會擋住遊玩，放大後再繼續。
