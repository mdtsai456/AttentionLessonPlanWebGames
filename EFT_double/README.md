# 漂浮泡泡・雙人

左右各一位玩家。記泡泡、看箭頭、計分與升級規則和單人相同，見 [`../EFT_single/README.md`](../EFT_single/README.md)。

## 和單人的差別

兩人各有一個 `shared/eft-player.js` 的玩家，連擊、箭頭階數與素材互不影響。素材用各自的個案編號向平台要 `EFT.assets.files`。同一個學生編號可以共用一次請求。

| 玩家 | 按鍵 |
| --- | --- |
| 玩家 1（左） | `A` 向左、`D` 向右 |
| 玩家 2（右） | `←` 向左、`→` 向右 |

每一關 60 秒、共 6 關，單題 10 秒沒答算錯。某人打完一關後會等另一位；第 3 關結束同樣先等齊，再一起離開中場。六關都完成才結束。

遊戲進行中直接關分頁、重新整理或按上一頁，會先跳出瀏覽器的離開詢問（`guardUnload`），打完六關後不問。按「離開」會先在頁面內問「確定要離開嗎？」（`shared/leave-confirm.js`），確認框開著時遊戲暫停；按「繼續遊戲」或 Esc 什麼都不送、遊戲照常繼續。按「離開」確定後，若兩人都至少打完第 3 關，會各送一筆到該檢查點，送完直接回選擇遊戲頁，不再跳出瀏覽器的離開詢問。中場的「返回遊戲大廳」是明確的選擇，不再確認，同樣先送兩人第 3 關再回大廳。每位玩家打完六關時自動送自己的第 6 關。同一局的同一個檢查點每人只送一次（連點、中場返回後再離開都不重送），已送過第 6 關的人離開時也不會再送第 3 關；伺服器明確拒絕（4xx，408 除外）時，同一頁下次存檔可以重送。確定離開後遊戲維持暫停到導頁，存檔期間兩位玩家的按鍵與答案按鈕都不算作答。成績只算到該關結束為止，第 4、5 關中途離開不會混入後面關卡的題目；`endTime` 也是該關結束當下，`endTime − startTime` 等於 `EFT_duration`。`lessonId` 為 `1140908_EFT`，`mode` 為 `double`，兩人帶同一組 `pairId`（UUID，由共用的 `WebGameApi.uuid()` 產生），`startTime` 是牆上時間。

中場畫面時「離開」仍在最上層可以按。

先打完六關的人，結果畫面的「再玩一次」會停用到另一位也打完。兩人都打完後，任一人按「再玩一次」兩人一起開新的一局，換新的 `pairId`。
