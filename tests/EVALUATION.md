# 動物追擊令桌面穩定性評估

驗收日期：2026-10-05。範圍為根目錄 `DAT_single/`、`DAT_double/`，macOS 桌面 Google Chrome 155.0.8059.26，鍵盤及滑鼠。原生遊戲手柄、手機及其他瀏覽器不在本次範圍。

## 結論與判定標準

已確認主要遊玩流程可完成，已重現的素材載入、存檔狀態及雙人重玩問題已修正。這是限定環境與已測情境的驗收證據，不是「程式在任何條件下完全正確」的保證。

接受標準：單／雙人各完成練習轉正式六關及第二局；每位玩家每局只送一次最終成績；兩位玩家同步重玩且新 pairId 不混用；素材失敗可用有效備援圖繼續；存檔狀態實際可見，明確失敗可人工重試，未知結果不自動重送或丟棄結算。

提交前完整 `cd tests && npm test`：54／54 通過（20 單元、34 Chrome 瀏覽器），0 失敗／跳過，約159秒。單元測試執行實際共享 script；瀏覽器測試使用安裝的 Google Chrome。

後端全套 `cd backend && env -u TEST_DB_NAME uv run pytest -q`：162 通過、97 跳過、1 失敗。既有 `test_game_lobby_and_dccs_are_served` 要求 `/app/games.html`，但 HEAD 中沒有 `frontend/games.html`，回傳404。此測試、靜態掛載及 frontend 副本皆未在本次修改；不可把整個專案測試描述為全綠。需要資料庫的97項因未設定隔離測試庫而跳過。

## 修正前後的依據

- 初始壞圖修正前兩版自然尺寸為0；修正後通過可見備援圖片驗證。
- API 懸置修正前等待超過31秒仍在載入；目前素材清單與圖片各有5秒期限。
- 單人漏答／正確等待回饋修正前被下一題覆蓋；回歸測試先失敗再通過。
- HTTP500修正前沒有使用者可見提示；修正後保留結算並提供人工重試。
- 雙人練習的正式按鈕被離開鈕遮擋；保留真實滑鼠點擊的測試找到問題，調整位置後通過。
- 獨立審查以隔離VM重現代理504後重試造成第二次寫入；已改未知狀態，新增回歸測試先失敗再通過。

## 測試方法與限制

採獨立瀏覽器 context，攔截全部外部流量並控制回應；符合 Playwright 對使用者可見行為、隔離測試及模擬第三方服務的[官方建議](https://playwright.dev/docs/best-practices)。完整兩局使用[官方 Clock API](https://playwright.dev/docs/clock)加速時間及固定命中，另以真實幾何操作與真時鐘案例補驗；不能將假時鐘完整流程當成長時間實機手感測試。

未測正式遠端素材／成績 API、真實 MariaDB 寫入與持久性、跨分頁並行、長時間效能、瀏覽器關閉或重新整理後恢復未存成績。本次保留未存成績是在目前頁面記憶體中。網路結果未知時停止重送並提示先確認紀錄；後端每次新建UUID，沒有端到端冪等保證，不能聲稱所有代理／資料庫故障都只寫入一次。HTTP500的人工重試沿用後端寫入失敗回應契約，若資料庫 commit 本身結果不明，仍需人工核對。

根目錄動物追擊令的資料分類沿用 `lessonId: 1140908_EFT` 及 `EFT_*` 統計。`DAT_*` 目錄名稱不代表應改成 DAT；已對照入口及後端契約。`frontend/` 舊副本由後端 `/app` 掛載，本次沒有同步修改或宣稱該副本通過根目錄遊戲驗收。
