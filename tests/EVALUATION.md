## 測試方法與限制

採獨立瀏覽器 context，攔截全部外部流量並控制回應；符合 Playwright 對使用者可見行為、隔離測試及模擬第三方服務的[官方建議](https://playwright.dev/docs/best-practices)。完整兩局使用[官方 Clock API](https://playwright.dev/docs/clock)加速時間及固定命中，另以真實幾何操作與真時鐘案例補驗；不能將假時鐘完整流程當成長時間實機手感測試。

未測正式遠端素材／成績 API、真實 MariaDB 寫入與持久性、跨分頁並行、長時間效能、瀏覽器關閉或重新整理後恢復未存成績。本次保留未存成績是在目前頁面記憶體中。網路結果未知時停止重送並提示先確認紀錄；後端每次新建UUID，沒有端到端冪等保證，不能聲稱所有代理／資料庫故障都只寫入一次。HTTP500的人工重試沿用後端寫入失敗回應契約，若資料庫 commit 本身結果不明，仍需人工核對。

根目錄瓢蟲追擊令的成績代號是 `lessonId: 1140908_DAT` 及 `DAT_*` 統計。`frontend/` 舊副本由後端 `/app` 掛載，本次沒有同步修改或宣稱該副本通過根目錄遊戲驗收。


## 雙人兔子→貓→兔子症狀複驗

2026-10-05再次核對後，發現上一輪素材測試接受「任何變身圖失敗都回兔子」，沒有涵蓋已變成貓後再升級的圖片故障。新增 Chrome 測試先重現兩個失敗：兩位玩家各連續答對5題成為貓，再答對5題時下一張圖404或超過5秒期限，貓被預設兔子取代。

本輪只調整雙人升級圖片的回退來源：使用目前已顯示的有效圖片。初始載入沒有有效圖時仍使用兔子。圖片非同步世代保護保留；更新HTML入口與module快取版本。新的404／逾時回歸測試使用實際貓圖片，等待超過載入期限後檢查src、自然尺寸、可見性、透明度與尺寸還原；接著誤按，確認正常紅色判定仍存在、貓不降級、沒有未處理的JavaScript例外。兩案先失敗再通過，相關素材測試15／15通過。

本輪完整前端 `cd tests && npm test`：56／56通過（20單元、36 Chrome瀏覽器），0失敗／跳過，約166秒。涵蓋單／雙人練習轉正式六關、第二局、鍵盤／滑鼠及素材／存檔失敗情境。後端全套本輪複驗仍為162通過、97跳過、1項既有失敗，詳見上方說明；後端沒有修改，正式API與資料庫寫入依舊不在實測範圍。

另以唯讀HTTP請求檢查[正式網站的雙人程式](https://attention-webgames.zeabur.app/DAT_double/js/game.js)，當時仍包含`switchToPrevAnimal()`，在誤按／漏答／未瞄準時呼叫；入口仍載入`main.js?v=5`、`game.js?v=4`。所以本機修正通過不代表正式網站已部署修正。使用者不確定當時版本及紅色提示種類，無法斷言原先畫面來自上述哪一種原因；目前已分別確認舊版降級邏輯及本機圖片故障缺口。


本輪第一次全套出現單人升級圖的測試時序失敗：測試工具原本只快轉300ms，就假定非同步HTTP／圖片解碼完成。工具已改為等待圖片完整載入（或回退）與預載狀態結束，保留原有升級判定斷言。動畫透明度與縮放採實際畫面時間等待，避免把尚在transition中的畫面判成錯誤。單人及新增雙人案例7／7複驗通過。
