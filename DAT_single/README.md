# 瓢蟲追擊令・單人

畫面上的標題是「動物追擊令」。選單、資料夾與成績代號都是 `DAT`。

玩家移動準心去疊住動物。動物中央一圈一定算瞄準；圈外看目前顯示的那張圖，透明處不算。讀不到上傳圖的透明度時（跨網域），只算中央一圈。題目要求按鍵時，準心在動物上才算對；要求不要按時，時間內不要按。按錯、沒瞄準或逾時都算錯。

## 一局怎麼進行

網址決定模式：

- `?mode=practice`：練習，1 關、2 題，顏色題與數學題各一題。
- `?mode=game`：正式，6 關，每關 60 秒。時間內答完會繼續出題。

每一題最多 10 秒。正式題型是顏色判斷（色名與字色是否相同）與數學判斷（算式答案是否正確），每題隨機。

打完第 3 關可以回選遊戲頁，這時會送中場成績。第 4、5 關按離開也是送這筆第 3 關成績，題數、答對、時長與反應時間都只算到第 3 關結束。六關結束再送完整成績。

遊戲中按「離開」會先在畫面上問「確定要離開嗎？」（`shared/leave-confirm.js`）。按「繼續遊戲」或 Esc 什麼都不送，遊戲照常進行；按「離開」才存上面的檢查點，再回選遊戲頁。確定後到導頁前遊戲維持暫停，按鍵與作答鈕都不算，存檔期間不會打完下一關多送一筆；存檔請求最多等 10 秒，暫停中照樣會逾時。存檔沒成功（失敗、結果未確認）就留在遊戲頁，遊戲恢復進行，可以按「重試儲存」或再按一次「離開」；再按離開會用同一筆成績重送，成功才回選遊戲頁。打完六關後的「離開」也一樣：最終成績還沒存好就先重送。打完六關或練習結束後的「離開」、「返回遊戲大廳」，以及第 3 關中場的「返回遊戲大廳」不再確認，直接存檔回大廳。遊戲進行中關分頁仍會跳出瀏覽器的離開詢問；從上述按鈕離開時不會。

操作：`W` `A` `S` `D` 或方向鍵移動，空白鍵作答。

## 動物圖

連續 5 題都答對且準心在動物上，動物升一張。答錯、漏答或沒瞄準只把連擊歸零，已經換成的動物留著。門檻是 `STREAK_TO_EVOLVE`。連擊中提示還要再對幾題，中斷時提示連擊歸零。到最後一張後維持該張。

圖的順序來自素材平台：

`https://attention-lesson-plan-assets.zeabur.app/api/students/{學生ID}/assets`

學生 ID 用個案編號補成三位數，例如 `S01` 打成 `S001`。網址不含年級與場域。回應讀 `DAT.assets.files`。沒有客製圖、請求失敗，或只有一張時，用 `assets/animals/` 的兔子、貓、狗、鳥補上。圖片要載入完成才換上去。

成績裡的 `caseId` 仍用原本的編號，不補成三位數。

## 成績

`lessonId` 是 `1140908_DAT`，統計欄位前綴是 `DAT_`。送出與畫面上的儲存狀態在 `shared/dat-save.js`。每筆成績第一次送出時帶一個 `data.submissionId`（`WebGameApi.uuid()` 產生的 UUID v4），重送沿用同一個 body。後端用「學生身分 + submissionId」決定場次編號，重複收到同一筆會回同一個 `sessionId`，不會多一列。所以網路中斷或逾時（結果未確認）時不會自己重送，但玩家按「重試儲存」或按「離開」時會用同一個 submissionId 重送，不會被卡住。重玩、新的一局、不同關卡的紀錄都是新的 submissionId。第 3 關中場成績結果不明時，六關結束仍照常送完整成績，畫面顯示這筆完整成績的狀態。反過來，已經送過較高關卡（例如第 6 關）就不再送較低的檢查點：已儲存當作完成；結果未確認或失敗時改重送那一筆較高關卡。

`DAT_avgReactionMs` 只平均有按鍵的題目（從出題到按下的時間）；「不要按」而等滿 10 秒或漏答的題目沒有反應時間。
