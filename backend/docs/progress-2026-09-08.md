## 4. 怎麼啟動 Demo 畫面

開一個 PowerShell 視窗，`cd` 到專案資料夾：

```powershell
git checkout integration          # 切到完整版分支
uv run uvicorn main:app --port 5001
```

看到 `Application startup complete` 後，瀏覽器開：

| 網址 | 是什麼 |
|---|---|
| `http://127.0.0.1:5001/demo` | Demo 畫面 |
| `http://127.0.0.1:5001/docs` | API 文件（可逐一點端點試） |

**Demo 操作**：老師端 → 選場域（高雄醫學大學）→ 選老師（吳老師）→ 點學生 → 看報告。
或直接開 `http://127.0.0.1:5001/demo?school=KMU&student=G1_S01` 跳到報告頁。

關掉 PowerShell 視窗 = 停掉伺服器。

### 假資料被清掉時重灌

```powershell
uv run python seed.py
uv run python seed_directory.py
```

## 5. 怎麼跑測試

```powershell
uv run pytest -q
```

連遠端資料庫，一輪約 2–3 分鐘。**切換分支後**（例如從 main 切到功能分支）第一次跑
可能要先重建 `_test`，因為 `schema.sql` 用 `CREATE TABLE IF NOT EXISTS`，不會自動補
新欄位：

```powershell
uv run python -c "import pymysql; c=pymysql.connect(host='43.163.233.40',port=31497,user='root',password='<看 .env>'); cur=c.cursor(); cur.execute('DROP DATABASE IF EXISTS AttentionLessonPlan_test'); cur.execute('CREATE DATABASE AttentionLessonPlan_test CHARACTER SET utf8mb4'); c.commit()"
```
